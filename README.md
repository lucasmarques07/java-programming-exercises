# Lista de Atividades Práticas de Programação Java

Este repositório reúne atividades desenvolvidas como parte de um **trabalho acadêmico da faculdade**, com o objetivo de aplicar, na prática, os conceitos estudados na disciplina de programação em Java.

Os exercícios abordam desde tipos de dados e **Programação Orientada a Objetos (POO)** até recursos como enumerações, tratamento de exceções, threads e interfaces gráficas com Java Swing.

## Conteúdos abordados

- **Parte I – Tipos de dados e POO:** classes, objetos, atributos, métodos, construtores e encapsulamento.
- **Parte II – Enumerações:** utilização de `enum` para representar conjuntos de valores fixos.
- **Parte III – Exceções:** validação de dados, `try/catch`, `throw`, `throws` e exceções personalizadas.
- **Parte IV – Threads:** execução concorrente de tarefas e sincronização com `synchronized`.
- **Parte V – Java Swing:** criação de interfaces gráficas e interação com o usuário.
- **Parte VI – Desafio integrador:** sistema de gerenciamento de pedidos que reúne os conteúdos anteriores.

## Organização do repositório

As pastas `parte-01` a `parte-06` contêm os exercícios organizados por assunto. Cada tarefa inclui os arquivos Java e um documento `CONCEITOS_UTILIZADOS.md` que explica os recursos aplicados.

A pasta **[LISTA DE POO](LISTA%20DE%20POO)** reúne uma cópia das atividades, com os códigos-fonte e os documentos de conceitos convertidos para **PDF**, em um formato organizado para a entrega acadêmica.

## Execução

Os programas foram desenvolvidos em **Java** e podem ser compilados e executados utilizando um JDK compatível. Algumas atividades utilizam entrada de dados pelo terminal, enquanto as atividades de Swing apresentam janelas gráficas.

Como os exercícios são independentes, cada tarefa deve ser executada separadamente. As atividades que possuem pacotes Java devem respeitar a estrutura de pastas indicada no código.

## Objetivo

O propósito deste trabalho é consolidar o aprendizado dos fundamentos de Java e da Programação Orientada a Objetos por meio de exercícios práticos, com foco na organização do código, na resolução de problemas e na aplicação dos conceitos estudados durante o bimestre.
