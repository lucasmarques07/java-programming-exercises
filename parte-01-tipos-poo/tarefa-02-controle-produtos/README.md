# Tarefa 02 – Sistema de controle de produtos

## Objetivo

Desenvolver um programa Java para cadastrar e exibir as informações de um produto, além de calcular o valor total dos itens disponíveis em estoque.

## Funcionalidades

- Cadastrar código, descrição, preço, quantidade em estoque e categoria de um produto.
- Exibir os dados cadastrados.
- Calcular o valor total em estoque multiplicando o preço pela quantidade.

## Conceitos utilizados

- Tipos de dados: `int`, `double` e `String`.
- Programação orientada a objetos: classes, atributos privados, construtor e objetos.
- Encapsulamento: getters e setters.
- Métodos `exibirDados()` e `calcularValorTotalEstoque()`.
- Entrada de dados com `Scanner`.

## Como executar

No terminal, dentro da pasta `tarefa-02-controle-produtos`, execute:

```bash
javac -d out src/Produto.java src/Main.java
java -cp out Main
```

Informe os dados solicitados. Para o preço, utilize o separador decimal aceito pelas configurações regionais do seu computador.
